## Home announcements (`src/features/home/components/announcements/`)

Data (`src/features/home/data.js`, `HOME_ANN`): each post is `{ d, t, x, pin?, at?, jump? }`.
- `d`: the team that posted. One of `HR`, `Admin` or `PFM`. PFM is new.
- `t`: the posting time, written in Thai, e.g. `13 ต.ค 69, 10:30 น.`. A backend should store this as a real timestamp.
- `at`: a list of attachments, each one of:
  - `{k:'link', t, u, h, dsc}`: title, URL, host and description.
  - `{k:'file', n, s, x}`: file name, size and type, e.g. `PDF`. The download button is a demo for now.
  - `{k:'video', t, len}`: title and length. The player is a mock.
  - `{k:'img', n:[urls]}`: a photo set. Up to 4 tiles show, then "+n", and tapping opens a lightbox.
- `jump`: `{to, l}` links to the page with the details ("ดูรายละเอียดที่หน้า …").

Search and filter (client-side for now):
- The keyword matches the team, time, text, link title and file name.
- Teams can be filtered by checkbox.
- Dates can be filtered by "all", "last 7 days", "last 30 days" or a from/to range.
- An API would need the query parameters `q`, `teams[]`, `from` and `to`.

UI:
- The card has a fixed height (716px, or 560px on phones) and the list scrolls inside it. Text is cut to 2 lines.
- "ดูประกาศทั้งหมด" now opens a popup that shows full text and shares the same filter. It no longer links to /news.

## Birthday cards (`src/features/birthday/`)

Card model changes:
- `cover` is now required. New cards default to the first cover.
- New field `paper` holds the inside paper colour. It is one of 8 pastels (`BD_PAPERS`): cream, pink, peach, butter, mint, sky, lav, sage.
- A card has two faces:
  - The cover face shows the cover plus a "จาก <nick>" chip.
  - The inside face shows the paper with the message, the footer and the stickers.
- Cards open with a flip. The reader auto-opens them.

Sticker kinds in `stk[]` (still max 12, positions in %):
- `{e, x, y, s, r}`: an icon or a Terby sticker.
- `{t, c, ff, b, i, x, y, s, r}`: text.
  - Max 60 characters, may be multi-line.
  - `ff` is the font family, picked from 8 fonts: Sarabun, Mali, Gaegu, Allura, DM Serif Display, Montserrat, Poppins, Josefin Sans.
  - `b` is bold (0 or 1), `i` is italic.
  - `c` is one of 9 colours.
- **New** `{ph:[albumIndex, photoIndex], x, y, s, r}`: a photo from an Activity album, shown as a polaroid. A backend would reference real photo IDs instead of indexes.

Removed in v241:
- Theme picker. `theme` is kept only for old cards without a cover.
- Corner-sticker picker.
- Gift Tag. The `gift` field and the "Gift Tag n" count in the book header are both gone.

Composer UI:
- Sections fold open and shut.
- From 900px wide it uses two columns with the preview kept in view.
- The header stays fixed while the body scrolls.
- The text toolbar has font, bold, italic, size, edit and colour.

The book itself is unchanged: the owner's book opens with all cards heaped at once.
